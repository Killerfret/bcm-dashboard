## ⚡ Quick reference

### De Tijdlijn (KEN UIT JE HOOFD)
```
Vredestijd | Oorlogstijd                                    | Vredestijd
   ◄─ RPO ─►◄─ RTO ─►◄─ WRT ─►◄─────── RT ───────►◄── BAU ──►
   ◄────────────── MAO ──────────────►
```
**MAO = RTO + WRT** (uiterste grens — voorbij = bedrijf failliet)

### De 3 Frameworks
| Framework | Origin | Structuur |
|-----------|--------|-----------|
| ENISA RM+BCM | 🇪🇺 EU 2004 | 4 Kwadranten |
| NIST CSF | 🇺🇸 USA | 5 Functies |
| ISO 22301 | 🌍 Internationaal | PDCA Cyclus |

- **Stap 1** Bedrijfscontinuïteit NU!!! (Workshop "Red de organisatie")
- **Stap 2** Optimaliseren (IST vs SOLL → GAP-analyse)
